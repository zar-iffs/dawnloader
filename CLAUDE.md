# CLAUDE.md - project guide

Dawnloader: local Windows media downloader (renamed from "YT Downloader"; old %LOCALAPPDATA%\YTDownloader\tools and ytdl-settings.txt are migrated automatically). `Start Dawnloader.bat` runs `dist/Dawnloader.ps1`, which compiles the embedded
C# WinForms UI once (cached as `%LOCALAPPDATA%\Dawnloader\ytd-<hash>.dll`) and calls `[YTD.Program]::Run($ScriptDir)`.
It drives yt-dlp, ffmpeg and deno. Supports YouTube, TikTok, Instagram, Facebook, X, Google Drive (incl. private),
direct links, playlists, size estimates, inline clip trimmer, download history, clipboard catcher, browser-icon sign-in picker, site-icon header, five skins, per-link sign-in, and a built-in installer for missing tools.

## Source of truth
- `src/ytd.cs` - all app code. Edit this.
- `src/launcher.template.ps1` - PowerShell wrapper; `@@CSHARP@@` marks where the C# goes.
- `dist/Dawnloader.ps1` - generated by `python3 tools/build.py`. Never edit by hand; rebuild after every change.

## Hard constraints (the build script checks the first two)
1. Output must be ASCII only. Write non-ASCII characters as `\uXXXX` in C# strings.
2. No line in `ytd.cs` may start with `'@` (it would close the PowerShell here-string).
3. C# 5 only (Windows PowerShell 5.1 `Add-Type`): no `$"..."`, `?.`, `nameof`, expression-bodied members, `out var`.
4. References available: System, System.Windows.Forms, System.Drawing, System.Web.Extensions, System.IO.Compression.
5. Deliverable is CRLF. The launcher is started with `-STA -ExecutionPolicy Bypass -NoProfile`.

## Behaviour rules worth keeping
- `-S` format sorting; non-YouTube sites prefer H.264 up to 1080p (H.265 fails on many PCs/TVs); "Best available" keeps highest res.
- The size estimator in `Est` mirrors yt-dlp's `-S` ordering (width/height minimum for vertical video). `tests/esttest.cs` compares it with real yt-dlp picks.
- Tools install into `%LOCALAPPDATA%\Dawnloader\tools`; `YTD_TOOL_MIRROR` env var redirects downloads for tests.
- YouTube 403: fall back across extractor-args player clients. Instagram usually needs sign-in (Firefox recommended).
- Settings file `dawnloader-settings.txt` sits next to the script (git-ignored).

## Testing (Linux sandbox, not real Windows)
UI was exercised under Mono + Xvfb + xdotool with a fake or real yt-dlp (`tests/sandbox/run_*.sh`, paths assume `/home/claude/app`;
adjust). Compile check: `mcs -langversion:5 -r:System.Windows.Forms -r:System.Drawing -r:System.Web.Extensions -r:System.IO.Compression src/ytd.cs`.
Estimator test: `tests/esttest.cs` with the JSON in `tests/sim/`.
NOT yet verified on real Windows PowerShell 5.1, real Instagram/X/Google sign-in, or antivirus behaviour on tool downloads.
Please smoke-test on a Windows machine after any UI or launcher change.

## Before shipping
Windows PowerShell `Add-Type` treats compiler warnings as errors (e.g. a member named like an inherited
`Control` member - `Site`, `Move` - stops the app from starting). Run `tools/check_windows_compile.sh` after
`tools/build.py`; it compiles the shipped code with Microsoft's compiler and warnings-as-errors.
The launcher also passes `-IgnoreWarnings` as a safety net.

## Releasing an update
Bump `AppVersion` in src/ytd.cs (e.g. 2026.11.1 -> 2026.11.2), run `python3 tools/build.py` (it writes `VERSION` and `dist/Dawnloader.ps1`), rebuild `releases/Dawnloader-2026.11.zip`, commit and push all of them together. About > Check for updates reads `VERSION` from the main branch and "Update now" downloads `dist/Dawnloader.ps1`, so they must always be pushed in the same commit.
